# 接入飞书（Agent 信鸽）

本机的「Agent 信鸽」App 把**一个 Agent 会话 = 飞书里的一个话题**双向绑定：话题里发言会进到这个会话，会话的输出会以流式卡片和结论卡回到话题。话题标题形如 `[Codex] 会话标题`，一眼能看出来自哪个 Agent。

## 一行接入

用户要“接入飞书”时，直接运行（不用再问确认）：

```bash
{{HT}} open --agent {{AGENT}} --session "{{SESSION_EXPR}}" --cwd "$PWD" --title "<话题标题>"
```

- `<话题标题>`：用户给了就用用户的；没给就用一句话概括当前对话（≤20 字），或者省略 `--title` 让桥用会话自己的标题。
- 输出 `已接入` 即成功，`已经接过了` 表示这个会话之前已经接入，把结果原样简短告诉用户即可。
- 输出「没有在运行」：提醒用户打开「Agent 信鸽」App（菜单栏图标）。
{{SESSION_NOTE}}

## 其他命令

```bash
{{HT}} ask --agent {{AGENT}} --session "{{SESSION_EXPR}}" --question "问题" --options "选项A|选项B"   # 发提问卡；回答会作为新消息回到会话，发完直接结束本轮
{{HT}} close --agent {{AGENT}} --session "{{SESSION_EXPR}}"   # 断开飞书话题
{{HT}} status                                         # 桥的运行状态
```

## 注意

- 只在用户要求时接入；不要自作主张暂停转发、改标题或发提问卡。
- 接入后，用户在飞书里发的消息会作为新的一轮进入本会话；回复里写出完整文件路径（在本会话工作目录内、本轮产生的文件）会被自动回传到飞书。
- 渠道与 Agent 的设置在「Agent 信鸽」App 的窗口里（菜单栏图标 → 打开 Agent 信鸽）。
