# 0002 一张流式过程卡加一张结论卡

- 状态：已采纳（2026-09-24，v1 定下，v0.3 沿用）

## 决策

一轮对话在话题里呈现为：

1. 一张流式过程卡：运行中逐字刷新正文、状态行和工具步骤，带「停止」按钮；收尾后折叠成一个面板，去掉按钮。
2. 一张单独的结论卡，内容是本轮最后一条助手消息。

阅读顺序固定为：问题、过程、答案。

## 放弃的方案

- **新消息来了就让出卡片，回答续到下一张卡**：用户不喜欢停在半截的卡片，已经否掉。
- **收尾后再补发一条纯文字**：和结论卡重复。
- **每条助手消息各发一条**：在手机上刷屏。

## 后果

- 所有对卡片的写入都必须串行，并且 sequence 严格递增，见 [feishu-cards.md](../subsystems/feishu-cards.md)。
- 排队的下一轮必须等上一轮的结论卡发出后再建卡（v0.3 加了 `settled` 门控）。
