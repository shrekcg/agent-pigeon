# 0005 渠道只保留「按会话隔离」一个开关

- 状态：已采纳（2026-10-30，取代 v0.2 配置页里的七个能力开关）

## 背景

v0.2 的配置页给每个渠道列了七个开关：流式卡、工具步骤、结论卡、回传文件、接收媒体、审批卡、Agent 端消息镜像。维护者的意见是：这些都是基础能力，不需要用户去勾选。

## 决策

- 流式过程卡、工具步骤、结论卡、审批卡、收发图片和文件、Agent 端消息镜像，一律作为固定行为。
- 每个渠道只剩一个用户能改的设置：**按会话隔离**。开就是每个会话一个话题（`thread`），关就是所有会话进同一个对话（`shared`）。
- 钉钉、QQ、微信在界面上只占位，不提供任何开关。

## 后果

- `channels/base.js` 里不再有 `CHANNEL_FEATURES`，渠道视图里也没有了按开关分支的代码。
- 如果以后某个平台确实做不到某项能力（比如没有卡片），由这个渠道的实现自己降级处理，不再暴露成开关。
