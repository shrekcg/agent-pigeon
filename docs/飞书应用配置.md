# 飞书应用配置

Agent 信鸽通过一个飞书**自建应用**的机器人收发消息。你已经在 PenguinHarness 里绑定过飞书机器人的话，Agent 信鸽会自动复用那份凭据，本文可以跳过。

## 1. 创建应用

1. 打开[飞书开放平台](https://open.feishu.cn/app)，点「创建企业自建应用」。
2. 在「添加应用能力」里添加「机器人」。

## 2. 权限

在「权限管理」里开通这些权限：

- 接收消息：`im:message:readonly`、`im:message.p2p_msg:readonly`
- 发送和更新消息：`im:message:send_as_bot`、`im:message:update`
- 上传和下载图片、文件：`im:resource`
- 流式卡片：`cardkit:card:write`、`cardkit:card:read`
- 表情回应审批卡：`im:message.reactions:read`

## 3. 事件与回调

在「事件与回调」页做三件事：

1. 订阅方式选「使用长连接接收事件/回调」。
2. 添加事件：`im.message.receive_v1`（接收消息）和 `im.message.reaction.created_v1`（用表情回应审批卡）。
3. 回调配置里添加「卡片回传交互」`card.action.trigger`。停止按钮和审批按钮靠它工作。

## 4. 发布

创建版本并发布，然后在飞书里找到这个机器人，给它发一条消息。这一步会生成单聊会话，Agent 信鸽要用到这个会话的 chat_id。

## 5. 填进 Agent 信鸽

编辑 `~/Library/Application Support/AgentPigeon/config.json`：

```json
{
  "channels": {
    "feishu": {
      "appId": "cli_xxx",
      "appSecret": "xxx",
      "chatId": "oc_xxx"
    }
  }
}
```

- `chatId` 是你和机器人单聊的会话 ID。查找方法：给机器人发一条消息，在 `logs/engine.log` 里搜 `chat_id`；或者调用飞书开放平台的「获取用户或机器人所在的群列表」接口。
- 改完在 App 的「设置」里点「重启引擎」。

> 同一个飞书应用同一时间只能有一个长连接。如果 PenguinHarness 的「远程控制」也用这个应用，请在 PenguinHarness 里关掉它的「启用连接」，否则两边会抢消息。
